# Edición de texto en un PDF

Aprende a editar palabras, frases o incluso páginas enteras en tu PDF. La edición de texto directamente en Acrobat le permite actualizar el contenido de forma precisa y profesional sin tener que cambiar de una aplicación a otra. Este tutorial de vídeo utiliza la [nueva experiencia de Acrobat](new-experience.md).
