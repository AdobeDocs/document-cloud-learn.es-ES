# Cuándo utilizar Crear una copia

Ya ha enviado un acuerdo, pero ha caducado, se ha cancelado o necesita enviarlo de nuevo. Crear una copia le permite duplicar cualquier acuerdo existente, ajustar lo que debe cambiar y volver a enviarlo en cuestión de segundos. Sin reconstrucción desde cero. Crear una copia está disponible cuando:

* Usted es el remitente original del acuerdo
* El acuerdo se ha enviado desde la experiencia moderna de firma de solicitud
* El acuerdo no incluye una función de destinatario testigo
* El acuerdo no se ha eliminado debido a la retención de documentos o a la eliminación del RGPD
* El acuerdo no requiere acceso a una plantilla de biblioteca a la que el remitente ya no tenga acceso

>[!NOTE]
>
>Crear una copia está disponible para los planes de nivel empresarial.
